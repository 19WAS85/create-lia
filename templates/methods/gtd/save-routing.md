## Save Routing

Route every saved change to its canonical location:

| Content | Destination |
| --- | --- |
| Unclassified capture | `inbox/` — until it is clarified |
| Captured commitment | the appropriate list in `next-actions.md`, `waiting-for.md`, or `someday-maybe.md` — a clarified item leaves `inbox/` |
| Project definition | `projects/<name>.md` |
| Reference material | `reference/<topic>.md` |
| Durable user facts | `reference/user-context.md` (canonical profile) plus a short useful summary in the `README.md` user context section |
| Tasks created, completed, cancelled, or reprioritized | the GTD lists named in the method chapter |
