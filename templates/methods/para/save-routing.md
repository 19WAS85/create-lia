## Save Routing

Route every saved change to its canonical location:

| Content | Destination |
| --- | --- |
| Active initiative | `projects/` — the matching project document |
| Ongoing responsibility | `areas/` — the matching area document |
| Workspace reference material (incl. reusable insight) | `resources/` — matching resource doc, or `resources/<domain>/<topic-kebab-case>.md` for cross-cutting domains |
| Durable user facts | `resources/user-context.md` (canonical profile) plus a short useful summary in the `README.md` user context section |
| Tasks created, completed, cancelled, or reprioritized | `TASKS.md` |
