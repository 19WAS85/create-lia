## Save Routing

Route every saved change to its canonical location:

| Content | Destination |
| --- | --- |
| New idea | `inbox/` as a fleeting note, promoted to `notes/<topic>.md` when it earns its place |
| Source summary | `sources/<topic>.md` |
| Navigation entry | the Map of Content in `notes/index.md` |
| Durable user facts | `notes/user-context.md` (canonical profile) plus a short useful summary in the `README.md` user context section |
| Tasks created, completed, cancelled, or reprioritized | `TASKS.md` |
